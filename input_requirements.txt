I want to build a web-based library management system. The system should allow users to register and login using their email and password. Users should be able to search for books by title, author, or ISBN. The system should allow users to borrow up to 3 books at a time. Borrowed books must be returned within 14 days. If a book is not returned on time, the system should automatically send an email reminder to the user. Admin users should be able to add, update, and delete book records. The system should show real-time availability of each book. The system should generate monthly reports of borrowed and returned books for the admin. The system should support at least 500 concurrent users without performance degradation. All user passwords must be stored encrypted. The system should be accessible from modern web browsers including Chrome, Firefox, and Safari. User sessions should expire after 30 minutes of inactivity.
