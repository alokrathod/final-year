I want to build a web-based marketplace system. The system should allow users to register and login using their email and password. Sellers should be able to list products with details such as price, description, and images. Buyers should be able to search and filter products by category, price, and ratings. The system should allow users to add products to a cart and place orders. The system should support secure payment processing. Users should be able to track their orders and view order history. Admin users should be able to manage products, users, and transactions. The system should generate sales and revenue reports. The system should support at least 800 concurrent users. All transactions must be securely handled and recorded.
