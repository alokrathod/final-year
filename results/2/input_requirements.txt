I want to build a web-based food delivery system. The system should allow users to register and login using their email and password. Users should be able to browse restaurants and view menus with prices and descriptions. The system should allow users to add items to a cart and place orders online. Users should be able to track their orders in real time. The system should support multiple payment methods including credit card and digital wallets. If an order is delayed, the system should notify the user via email. Restaurant admins should be able to add, update, and remove menu items. The system should generate daily and monthly sales reports. The system should support at least 1000 concurrent users. All payment data must be securely processed and stored.
