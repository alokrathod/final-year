I want to build a web-based learning management system. The system should allow users to register and login using their email and password. Students should be able to enroll in courses and access learning materials such as videos and documents. Instructors should be able to create, update, and delete courses. The system should allow instructors to upload assignments and quizzes. Students should be able to submit assignments and receive grades. The system should send email notifications for deadlines and announcements. Admin users should be able to manage users and courses. The system should track student progress and generate performance reports. The system should support at least 500 concurrent users. All user data must be securely stored and protected.
